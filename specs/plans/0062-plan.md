# Uygulama Planı: Spec 0062 — Akıllı Adaptif Filtreler ve Tek Sınıf/Çocuk Kilitlenmesi (Smart Adaptive UI)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KidsCare web panelindeki sahte çoğul seçimleri ("Faux Choice" / "Tüm Sınıflarım" anti-deseni) ve veli ekranındaki gereksiz sınıf/öğrenci filtrelerini tamamen kaldırıp, sektör standardı (Brightwheel/HiMama) akıllı adaptif filtre mimarisini (`useStudentScope` + `<AdaptiveScopeBadge />`) tüm ekranlara yerleştirmek.

**Architecture:**

1. `useStudentScope` hook'una `hasMultipleClassrooms`, `singleClassroom`, `hasMultipleChildren`, `singleChild` alanları eklenir; `showClassroomFilter` tek sınıflı öğretmen ve velide `false` dönecek şekilde akıllandırılır.
2. Sabit durumlar için şık, dokunsal ve erişilebilir `<AdaptiveScopeBadge />` bileşeni geliştirilir.
3. Fotoğraflardaki `ParentRequestsPage.tsx` başta olmak üzere `DevelopmentPage.tsx`, `MessagesPage.tsx` ve `IncidentsPage.tsx` ekranlarında tek sınıflı öğretmen için sahte dropdown kaldırılarak doğrudan sabit sınıf rozeti gösterilir; veli ekranından sınıf seçici tamamen silinir.

**Tech Stack:** React 19, TypeScript, Vitest, TailwindCSS, Lucide Icons.

## Global Constraints

- Never use `any` type in TypeScript code.
- No moving cards inside cards with buttons (Tactile Single Interactive Entity Rule).
- All changes must pass `./scripts/check.ps1` with 100% green output.

```ts
export interface UseStudentScopeResult {
  // ... mevcut alanlar
  hasMultipleClassrooms: boolean;
  singleClassroom: Classroom | null;
  hasMultipleChildren: boolean;
  singleChild: Student | null;
  // ...
}

// Implementasyon içinde:
const hasMultipleClassrooms = isStaff
  ? availableClassrooms.length > 0
  : isTeacher
    ? availableClassrooms.length > 1
    : false;

const singleClassroom =
  !isParent && availableClassrooms.length === 1 ? (availableClassrooms[0] ?? null) : null;

const hasMultipleChildren = isParent && availableStudents.length > 1;
const singleChild =
  isParent && availableStudents.length === 1 ? (availableStudents[0] ?? null) : null;

// Sınıf filtresi sadece birden fazla sınıf varsa gösterilir
const showClassroomFilter = isStaff || (isTeacher && availableClassrooms.length > 1);

// Öğrenci filtresi: Veli ise sadece birden fazla çocuk varsa gösterilir
const showStudentFilter = isParent ? availableStudents.length > 1 : true;
```

```tsx
import type { JSX } from 'react';
import { School, User } from 'lucide-react';

export interface AdaptiveScopeBadgeProps {
  type: 'classroom' | 'student';
  label: string;
  subLabel?: string;
  className?: string;
}

export function AdaptiveScopeBadge({
  type,
  label,
  subLabel,
  className = '',
}: AdaptiveScopeBadgeProps): JSX.Element {
  const isClassroom = type === 'classroom';
  const Icon = isClassroom ? School : User;

  return (
    <div
      className={`inline-flex items-center gap-2 px-3 py-1.5 rounded-2xl border-2 shadow-2xs font-bold text-xs select-none transition ${
        isClassroom
          ? 'bg-teal-50/80 dark:bg-teal-950/40 border-teal-300 dark:border-teal-700/60 text-teal-900 dark:text-teal-200'
          : 'bg-amber-50/80 dark:bg-amber-950/40 border-amber-300 dark:border-amber-700/60 text-amber-900 dark:text-amber-200'
      } ${className}`}
      title={subLabel || (isClassroom ? 'Sorumlu olduğunuz sınıf' : 'Öğrenciniz')}
    >
      <Icon
        className={`w-3.5 h-3.5 shrink-0 ${isClassroom ? 'text-teal-700 dark:text-teal-400' : 'text-amber-700 dark:text-amber-400'}`}
      />
      <span className="truncate max-w-[180px]">{label}</span>
      {subLabel && (
        <span className="text-[10px] font-medium opacity-75 hidden sm:inline">({subLabel})</span>
      )}
    </div>
  );
}
```

```tsx
const {
  isParent,
  isTeacher,
  isStaff,
  availableClassrooms,
  availableStudents,
  selectedClassroomId,
  setSelectedClassroomId,
  selectedStudentId,
  setSelectedStudentId,
  showClassroomFilter,
  showStudentFilter,
  singleClassroom,
  singleChild,
} = useStudentScope();
```

2. In filter bar:

```tsx
{
  /* Sınıf Filtresi VEYA Sabit Tek Sınıf Rozeti */
}
{
  showClassroomFilter ? (
    <div className="relative min-w-[150px]">
      <select
        value={selectedClassroomId}
        onChange={(e) => {
          setSelectedClassroomId(e.target.value);
          setSelectedStudentId('');
        }}
        className="..."
        aria-label="Sınıf Filtresi"
      >
        {isStaff && <option value="">🏫 Tüm Sınıflar</option>}
        {availableClassrooms.map((c) => (
          <option key={c.id} value={c.id}>
            {c.name}
          </option>
        ))}
      </select>
    </div>
  ) : singleClassroom ? (
    <AdaptiveScopeBadge type="classroom" label={singleClassroom.name} subLabel="Sınıfınız" />
  ) : null;
}

{
  /* Öğrenci Filtresi VEYA Sabit Tek Çocuk Rozeti */
}
{
  showStudentFilter ? (
    <div className="relative min-w-[160px]">
      <select
        value={selectedStudentId}
        onChange={(e) => setSelectedStudentId(e.target.value)}
        className="..."
        aria-label="Öğrenci Filtresi"
      >
        {!isParent && (
          <option value="">
            {singleClassroom ? `${singleClassroom.name} Öğrencileri` : 'Tüm Öğrenciler'}
          </option>
        )}
        {availableStudents.map((s) => (
          <option key={s.id} value={s.id}>
            {s.firstName} {s.lastName}
          </option>
        ))}
      </select>
    </div>
  ) : singleChild ? (
    <AdaptiveScopeBadge type="student" label={`${singleChild.firstName} ${singleChild.lastName}`} />
  ) : null;
}
```
