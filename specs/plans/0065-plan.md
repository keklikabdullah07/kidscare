- [ ] **Step 1: Connect `useAuth` and isolate Teacher audience choices**

1. `useAuth` hook'unu dahil et:

```tsx
import { useAuth } from '../auth/AuthContext';
```

2. Bileşen içinde rolü kontrol et:

```tsx
const { state: authState } = useAuth();
const isTeacher = authState.status === 'authenticated' && authState.user.role === 'TEACHER';
const currentUserId = authState.status === 'authenticated' ? authState.user.id : null;
```

3. Varsayılan `targetType` öğretmense `CLASSROOM` olsun:

```tsx
const [targetType, setTargetType] = useState<BroadcastTargetType>(() =>
  isTeacher ? 'CLASSROOM' : 'ALL_DAYCARE',
);
```

4. Öğretmen için sınıfları sadece kendi sınıfı olacak şekilde filtrele (`teacherClassrooms`):

```tsx
const displayClassrooms = useMemo(() => {
  if (!isTeacher) return classrooms;
  if (!currentUserId) return [];
  return classrooms.filter((cls) => cls.teachers?.some((t) => t.teacherId === currentUserId));
}, [isTeacher, currentUserId, classrooms]);
```

5. Öğretmen için öğrencileri sadece kendi sınıfındaki öğrenciler olarak filtrele (`displayStudents`).
6. Hedef Kitle Butonlarında:
   - `{!isTeacher && <button ... Tüm Kreş ... />}`
   - `{!isTeacher && <button ... Öğretmenler ... />}`
     Öğretmen sadece **"Sınıf Bazlı"** ve **"Öğrenci Bazlı"** butonlarını görebilsin.
