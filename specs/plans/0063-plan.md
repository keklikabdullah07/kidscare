# Uygulama Planı: Spec 0063 — Kapsamlı Rol İzolasyonu, Konsol Kartı Düzeni ve Dokunsal Rozet İyileştirmesi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Projedeki tüm menülerde veli/öğretmen/müdür rol izolasyonundaki `!isTeacher` zaafiyetini yok etmek; `ParentRequestsPage.tsx` üzerindeki sıkışmış filtre düzenini KidsCare'in 2 katmanlı Bütünleşik Konsol Kartı mimarisine kavuşturmak; `<AdaptiveScopeBadge />` renk ve yüksekliklerini dokunsal tasarım paletine tam uyumlamak.

**Architecture:**

1. `AdaptiveScopeBadge.tsx` içindeki renkler `bg-[#FCFAF7] border-2 border-[#DDD4C4] py-2` olarak güncellenir; form inputları ile tam aynı yükseklik (`h-10`) ve mat keten kontrastı sağlanır.
2. `ParentRequestsPage.tsx` içinde sekmeler ve filtreler `bg-white dark:bg-[#131B2E] border-2 border-[#DDD4C4] rounded-3xl p-4 sm:p-5 shadow-2xs space-y-4` konsol kartına taşınır. Üst katmanda `TactileTabs`, alt katmanda filtreler ve arama kutusu yer alır.
3. `ActivityGalleryPage.tsx`, `PickupPage.tsx`, `EventsPage.tsx` ve `AttendancePage.tsx` sayfalarında bulunan `!isTeacher` mantığı düzeltilir; veli (PARENT) kullanıcıların "Tüm Sınıflar & Kreş" gibi yetkisiz sınıf seçicilerini görmesi tamamen engellenir.
4. Testler ve tsc kontrolleri çalıştırılarak doğrulanır.

**Tech Stack:** React 19, TypeScript, Vitest, TailwindCSS.

```tsx
export function AdaptiveScopeBadge({
  type,
  label,
  subLabel,
  className = '',
}: AdaptiveScopeBadgeProps): JSX.Element {
  const isClassroom = type === 'classroom';
  const Icon = isClassroom ? School : User;

  return (
    <div
      data-testid={`scope-badge-${type}`}
      className={`inline-flex items-center gap-2 px-3 py-2 rounded-2xl border-2 border-[#DDD4C4] dark:border-slate-700/80 bg-[#FCFAF7] dark:bg-slate-900 shadow-2xs font-bold text-xs select-none transition ${
        isClassroom ? 'text-teal-950 dark:text-teal-200' : 'text-amber-950 dark:text-amber-200'
      } ${className}`}
      title={subLabel || (isClassroom ? 'Sorumlu olduğunuz sınıf' : 'Öğrenciniz')}
    >
      <Icon
        className={`w-3.5 h-3.5 shrink-0 ${
          isClassroom ? 'text-teal-700 dark:text-teal-400' : 'text-amber-700 dark:text-amber-400'
        }`}
      />
      <span className="truncate max-w-[180px]">{label}</span>
      {subLabel && (
        <span className="text-[10px] font-medium text-slate-500 dark:text-slate-400 hidden sm:inline">
          ({subLabel})
        </span>
      )}
    </div>
  );
}
```

- [ ] **Step 1: Update `ParentRequestsPage.tsx`**

`ParentRequestsPage.tsx` içerisindeki tek satırlık `flex-row justify-between` kapsayıcısını iki katmanlı Bütünleşik Konsol Kartı düzenine dönüştür:

```tsx
{
  /* Bütünleşik Konsol Kartı (Sekmeler & Filtreler) */
}
<div className="bg-white dark:bg-[#131B2E] border-2 border-[#DDD4C4] dark:border-slate-800 rounded-3xl p-4 sm:p-5 shadow-2xs space-y-4">
  {/* Üst Satır: Dokunsal Sekmeler */}
  <div className="overflow-x-auto pb-1 border-b border-slate-100 dark:border-slate-800">
    <TactileTabs<TabKey> tabs={filterTabs} activeId={activeTab} onChange={setActiveTab} />
  </div>

  {/* Alt Satır: Sınıf/Öğrenci Filtreleri ve Arama */}
  <div className="flex flex-wrap items-center justify-between gap-3">
    <div className="flex flex-wrap items-center gap-2.5">
      {/* Sınıf Filtresi — akıllı adaptif (Spec 0062) */}
      {scopeShowClassroomFilter ? (
        <div className="relative min-w-[150px]">
          <select
            value={selectedClassroomId}
            onChange={(e) => {
              setSelectedClassroomId(e.target.value);
              setSelectedStudentId('');
            }}
            className="w-full text-xs font-semibold border-2 border-[#DDD4C4] dark:border-slate-700/80 rounded-2xl px-3 py-2 bg-[#FCFAF7] dark:bg-slate-900 text-slate-800 dark:text-white focus:outline-none focus:border-teal-700 shadow-2xs cursor-pointer"
            aria-label="Sınıf Filtresi"
          >
            <option value="">🏫 Tüm Sınıflar</option>
            {(isTeacher ? teacherClassrooms : scopeAvailableClassrooms).map((c) => (
              <option key={c.id} value={c.id}>
                {c.name}
              </option>
            ))}
          </select>
        </div>
      ) : singleClassroom ? (
        <AdaptiveScopeBadge type="classroom" label={singleClassroom.name} subLabel="Sınıfınız" />
      ) : null}

      {/* Öğrenci Filtresi — akıllı adaptif (Spec 0062) */}
      {scopeShowStudentFilter ? (
        <div className="relative min-w-[160px]">
          <select
            value={selectedStudentId}
            onChange={(e) => setSelectedStudentId(e.target.value)}
            className="w-full text-xs font-semibold border-2 border-[#DDD4C4] dark:border-slate-700/80 rounded-2xl px-3 py-2 bg-[#FCFAF7] dark:bg-slate-900 text-slate-800 dark:text-white focus:outline-none focus:border-teal-700 shadow-2xs cursor-pointer"
            aria-label="Öğrenci Filtresi"
          >
            <option value="">
              {selectedClassroomId
                ? 'Sınıftaki Tüm Öğrenciler'
                : isTeacher
                  ? 'Sınıfımdaki Tüm Öğrenciler'
                  : 'Tüm Öğrenciler'}
            </option>
            {(scopeAvailableStudents.length > 0 ? scopeAvailableStudents : scopedStudents).map(
              (s) => (
                <option key={s.id} value={s.id}>
                  {s.firstName} {s.lastName}
                </option>
              ),
            )}
          </select>
        </div>
      ) : singleChild ? (
        <AdaptiveScopeBadge
          type="student"
          label={`${singleChild.firstName} ${singleChild.lastName}`}
        />
      ) : null}
    </div>

    {/* Arama Inputu */}
    <div className="relative w-full sm:w-72">
      <Search className="w-4 h-4 text-slate-400 absolute left-3 top-1/2 -translate-y-1/2 pointer-events-none" />
      <input
        type="text"
        placeholder="Talep veya öğrenci ara..."
        value={searchQuery}
        onChange={(e) => setSearchQuery(e.target.value)}
        className="w-full text-xs font-semibold pl-9 pr-8 py-2 border-2 border-[#DDD4C4] dark:border-slate-700/80 rounded-2xl bg-[#FCFAF7] dark:bg-slate-900 text-slate-800 dark:text-white placeholder-slate-400 focus:outline-none focus:border-teal-700 shadow-2xs transition"
      />
      {searchQuery && (
        <button
          type="button"
          onClick={() => setSearchQuery('')}
          className="absolute right-3 top-1/2 -translate-y-1/2 text-slate-400 hover:text-slate-600 dark:hover:text-slate-200"
        >
          <X className="w-3.5 h-3.5" />
        </button>
      )}
    </div>
  </div>
</div>;
```
