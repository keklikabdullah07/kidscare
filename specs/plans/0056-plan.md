# Uygulama Planı 0056: Dijital Veli Memnuniyet & Etkinlik Oylama Modülü (Anketler)

## Hedef

Kreş yönetimi ve veliler arasında hızlı geri bildirim ve etkinlik kararlarının alınabilmesi için Anket & Oylama modülünün uçtan uca Prisma, NestJS API, Shared Types/Schemas ve React Admin Web entegrasyonunun tamamlanması.

## Uygulama Adımları

### 1. Veri Tabanı Modelleri (`packages/database`)

- `packages/database/prisma/schema.prisma` içine:
  - `SurveyStatus` enum (`DRAFT`, `ACTIVE`, `CLOSED`)
  - `SurveyQuestionType` enum (`RATING_1_5`, `SINGLE_CHOICE`, `MULTIPLE_CHOICE`, `OPEN_TEXT`)
  - `Survey` modeli
  - `SurveyQuestion` modeli
  - `SurveyResponse` modeli
  - `SurveyAnswer` modeli
- `prisma db push` ve `prisma generate` çalıştırılması.
- `packages/database/src/index.ts` export güncellemeleri.

### 2. Paylaşılan Tipler ve Doğrulama Şemaları (`packages/shared-types`, `packages/shared-schemas`)

- `packages/shared-types/src/survey.ts`: `Survey`, `SurveyQuestion`, `SurveyResponse`, `CreateSurveyDto`, `SubmitSurveyResponseDto`, `SurveyStatsDto`, `SurveyDetailDto`.
- `packages/shared-schemas/src/survey.schema.ts`: Zod şemaları (`createSurveySchema`, `submitSurveyResponseSchema`).

### 3. API Katmanı (`apps/api/src/modules/surveys`)

- `SurveysRepository`: CRUD, tenant filtreli anket listeleme, soru ve seçenek ekleme, veli yanıtı kaydetme, analitik özet çıkarma.
- `SurveysService`: Anket yayınlama, kapatma, oy kullanma, oran/yüzde hesaplama.
- `SurveysController`:
  - `POST /surveys`: Admin anket oluşturma
  - `GET /surveys`: Anket listesi (filtreli)
  - `GET /surveys/:id`: Anket detay & istatistikleri
  - `PATCH /surveys/:id/status`: Anket durumu değiştirme (ACTIVE / CLOSED)
  - `POST /surveys/:id/respond`: Veli oyu/yanıtı kaydetme
  - `GET /surveys/stats/overview`: Genel anket metrikleri
- Tüm constructor parametrelerinde `@Inject(...)` kullanımı.

### 4. Web Paneli Arayüzü (`apps/admin-web`)

- `apps/admin-web/src/api/surveys.ts`: API istemcisi.
- `apps/admin-web/src/features/surveys/SurveysPage.tsx`:
  - 4 Dokunsal KPI Kartı (Aktif Anketler, Katılım Oranı, Ortalama Memnuniyet, Tamamlanan).
  - Sekmeler: `Aktif Anketler`, `Yeni Anket Oluştur`, `Tamamlanan / Arşiv`.
  - Yeni Anket Sihirbazı:
    - Hızlı Şablonlar: "Yemek Memnuniyeti", "Gezilecek Yer Oylaması", "Mezuniyet Konsepti", "Öğretmen Değerlendirme".
    - Dinamik soru ekleme / silme (Yıldız, Tekli Seçim, Çoklu Seçim, Yorum).
    - Canlı form önizlemesi.
  - Anket Analitik Kartları:
    - Canlı oy dağılım barları ve yüzdeleri.
    - Veli katılım listesi.
- `apps/admin-web/src/App.tsx`: `/surveys` rotası.
- `apps/admin-web/src/components/Layout.tsx`: `İletişim & Rutinler` altında `Vote` ikonuyla "Anketler" menü öğesi.
- `SurveysPage.test.tsx` birim testleri.
